# Workflow Tools

Katalog tools React premium + Pattern Picker + Stack Generator + Referensi per Niche — dibangun oleh Muse agent untuk Candra (candra304).

Buka `index.html` langsung di browser, atau aktifkan GitHub Pages (Settings → Pages → Deploy from branch `main` → `/ (root)`) untuk link live:
https://candra304.github.io/workflow-tools/

## Isinya

- **Katalog 42 kartu** — 28 tools + 14 referensi web live, 8 kategori: Core React, UI Kit, Animasi, 3D/WebGL, Scroll & Interaksi, Aset Premium, Referensi Web Live, Template/Starter.
- **Pattern Picker 4 pola super interaktif:** Drive/Explore (kayak Bruno Simon), Scroll Film (kayak Deep Sea / Lando Norris), Configurator/Game (kayak Scout & Bulgari), Game/Instrument (kayak Patatap).
- **Stack Generator:** perintah `npm install` gabungan + checklist build + conflict check (jangan 2 UI Kit, jangan 2 set 3D). Optimal 7–9 tools per build, max 12.
- **Referensi per Niche:** Finance / Trade / Prop Firm, Portfolio, E-Commerce (8 sub-model), Pendidikan/Instansi, SaaS, Agency, Real Estate, Kesehatan, Hotel — lengkap dengan harga, sales/skor, badge Trending / Top Rated / Baru Update, dan pola yang cocok. Diurutkan by peminat/popularitas, dengan label terakhir dicek.

## Cara kerja dengan Muse agent

1. Buka aplikasi Muse, kirim prompt — contoh: “Buatkan landing page Finance pakai pola Scroll Film”.
2. Muse mengeksekusi tools di balik layar (React, Next.js, Tailwind, GSAP, Three.js, dll — semuanya tanpa login, via npm).
3. Hasil demo tampil di **Muse Demo Hub** (`demo-hub/`) — web simple penampung semua bahasa/stack: HTML, CSS, JavaScript, React/Next.js, TypeScript, Tailwind, Python, dan lainnya. Tiap demo ada judul, prompt yang dipakai, bahasa/stack, tanggal, tombol Lihat Demo + Lihat Kode.
4. Kalau cocok, Muse push hasilnya ke repo ini.
